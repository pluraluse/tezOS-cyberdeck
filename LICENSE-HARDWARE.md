# Hardware License

All hardware design files under `hardware/` (PCB schematics/layouts,
enclosure 3D-print files) are licensed under the **CERN Open Hardware
Licence Version 2 — Permissive (CERN-OHL-P v2)**.

## Why this, and why separate from the software license

Software (`LICENSE`, MIT) and hardware designs use different licenses on
purpose — MIT is written for code, and stretching it over schematics and
mechanical files is a common but imprecise shortcut. CERN-OHL-P is the
actual license built for hardware artifacts, in the same permissive spirit
as MIT: anyone can use, modify, manufacture, and sell derivatives without
being required to open-source their own changes.

## Where to get the actual license text

Don't copy the license text from this repo — get the current, authoritative
version directly from CERN's OHL page (search "CERN OHL-P v2") and include
the official text file in `hardware/LICENSE` once hardware design work
actually begins. This file is a pointer and rationale, not the license
itself.
