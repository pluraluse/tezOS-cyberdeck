tezOS interactive clickthrough

This is a browser mockup of the navigation flow — idle screen menu through to every app's mockup screen and back. It mirrors the real softkey/Up/Down navigation model (see src/core/tezos_core.h for the actual C implementation this is modeled after), not the final pixel-exact UI.

Controls:
↑ / ↓ — move selection
Enter — select (left softkey)
Esc — back (right softkey)
Click works too — click a row to select it, click the softkey labels at the bottom of the screen.

Click the screen once first so it can capture keyboard input.
