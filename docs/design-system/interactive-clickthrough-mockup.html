tezOS interactive clickthrough

Every character on this screen — the idle menu, the scrolling list, every app screen — is drawn from the actual rasterized bitmap glyph data generated by tools/rasterize_font.py from the real Press Start 2P and MonoMEK font files, the same data used in src/core/fonts/. No web font is loaded at all; this page works fully offline.

Static labels and the scrolling menu are both drawn the same way — by blitting real glyph bitmaps onto a canvas, mirroring tezos_gfx.c's blit_glyph — rather than one approach for fixed text and a different fallback for anything that scrolls.

Controls:
↑ / ↓ — move selection
Enter — select (left softkey)
Esc — back (right softkey)
Click a row, or click the softkey labels at the bottom of the screen. Click the screen once first so it can capture keyboard input.
